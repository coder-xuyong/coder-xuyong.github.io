## 🏗️ 项目概览：`jwwd-flow`（经纬万达流程引擎）

这是一个 **Java 17 + Spring Boot 3.5** 的企业级工作流引擎项目，由 **经纬万达（JWWd）** 团队开发，核心功能是基于 **爱组搭（aizuda）FlowLong 工作流引擎** 构建的业务流程管理系统。

---

## 📦 技术栈一览

| 层次 | 技术 |
|------|------|
| **语言** | Java 17 |
| **框架** | Spring Boot 3.5.6 |
| **Web 容器** | Undertow（非 Tomcat） |

## 🔑 核心模块详解

### 1. 配置层 (`config/`)
- [BpmConfiguration.java](file:///D:/workspace_idea/jwwdflow/src/main/java/com/jwwd/flow/config/BpmConfiguration.java) — 工作流引擎核心配置，启用了定时调度 `@EnableScheduling`
- [MQConfig.java](file:///D:/workspace_idea/jwwdflow/src/main/java/com/jwwd/flow/config/MQConfig.java) — 定义了 **8 个 RabbitMQ 队列**（流程事件、启动、任务、实例、错误、停止、消息、拒绝），流程的异步处理全靠这些队列驱动

### 2. 流程核心模块 (`modules/flw/`)
这是项目的 **心脏**，建议从这里开始深入了解：

- **Controller 层**：提供了完整的 REST API
  - `ProcessController` — 流程定义管理（发起、分类、历史）
  - `ProcessInstanceController` — 流程实例管理
  - `ProcessTaskController` — 任务审批/驳回/转办/加签/跳转
  - `FormTemplateController` — 表单模板管理
  - `TransferConfigureController` — 转办配置

- **Flow 扩展层** (`flow/`)：对 FlowLong 引擎的定制化扩展
  - [FlowTaskAccessStrategy](file:///D:/workspace_idea/jwwdflow/src/main/java/com/jwwd/flow/modules/flw/flow/FlowTaskAccessStrategy.java) — 任务访问权限策略（判断用户是否有权操作任务）
  - [FlowTaskActorProvider](file:///D:/workspace_idea/jwwdflow/src/main/java/com/jwwd/flow/modules/flw/flow/FlowTaskActorProvider.java) — 提供任务参与者
  - [FlowTaskListener](file:///D:/workspace_idea/jwwdflow/src/main/java/com/jwwd/flow/modules/flw/flow/FlowTaskListener.java) — 任务事件监听
  - [FlowConditionNodeHandler](file:///D:/workspace_idea/jwwdflow/src/main/java/com/jwwd/flow/modules/flw/flow/FlowConditionNodeHandler.java) — 条件分支节点处理

- **消息消费** (`consumer/`)
  - [ProcessConsumer.java](file:///D:/workspace_idea/jwwdflow/src/main/java/com/jwwd/flow/modules/flw/consumer/ProcessConsumer.java) — 核心消息消费者，监听 RabbitMQ 各队列，处理流程的启动、审批、驳回、转办、终止等异步事件

### 3. 通用业务模块 (`modules/common/`)
定义了系统的基础数据模型：用户、角色、部门、网格、站点等，是流程模块的 **数据支撑层**。

## 💡 关键理解点

1. **这是一个微服务中的流程引擎服务**，使用 Undertow 而非 Tomcat，端口 `9209`，名称 `jwwd-flow`
2. **流程处理是异步的**：通过 RabbitMQ 的 8 个队列实现事件驱动，[ProcessConsumer](file:///D:/workspace_idea/jwwdflow/src/main/java/com/jwwd/flow/modules/flw/consumer/ProcessConsumer.java) 是异步处理的核心
3. **底层引擎是 FlowLong**：来自 aizuda 的开源工作流引擎，项目在此基础上做了大量业务定制
4. **数据存储多样化**：MySQL（关系型）、MongoDB（文档型）、Redis（缓存）、Caffeine（本地缓存）
