### 关闭防火墙
以下是图片内容转换成的可复制Markdown格式：

1. 命令行界面输入命令 `systemctl status firewalld.service` 并按下回车键。

2. 在下方查看输出结果，若显示 `active (running)`，说明防火墙已开启。

3. 输入关闭防火墙命令：  
   ```bash
   systemctl stop firewalld.service
   ```

4. 再次检查防火墙状态：  
   ```bash
   systemctl status firewalld.service
   ```  
   若出现 `inactive (dead)`，说明防火墙已关闭。

5. 永久禁用防火墙服务：
   ```bash
   systemctl disable firewalld.service
   ```

## 脚本

### 执行脚本
```shell
# 切换到脚本目录
cd /opt/meeting-file-sync
# 脚本执行环境+命令
./venv/bin/python sync_meeting_file.py full
# 也可以后台运行脚本，
nohup ./venv/bin/python sync_meeting_file.py full > sync.log 2>&1 &
```
- `nohup`：全称 No Hang UP，不挂断
- `> sync.log`：重定向标准输出
- `2>&1`：重定向错误输出
  + `2`：代表标准错误输出（stderr）的文件描述符编号（Linux 中：0=标准输入，1=标准输出，2=标准错误）。
  + `>&`：将左边的文件描述符（2）复制/重定向到右边的目标（1）。
  + `1`：代表标准输出（stdout）。
  + `&`：最后的`&`，表示放在后台执行

### 设置 jar 开机自启
编写脚本文件
`start.sh`
```shell
#!/bin/bash
nohup java -server -jar XXX.jar > /dev/null 2>&1 &
#nohup 确保即使用户退出登录，Java进程也会继续运行。
#java -server -jar XXX.jar 启动指定的JAR文件。
#-server 是一个JVM选项，表示以服务器模式运行JVM。服务器模式下的JVM通常会进行更多的优化，适合长时间运行的应用程序。
#> /dev/null 将标准输出（控制台输出）丢弃。
#2>&1 将标准错误（错误信息）也丢弃。
#& 将整个命令放在后台执行。
```
进入 rc.d目录
```shell
cd /etc/rc.d
cat rc.local
```
执行命令：vim rc.local  , 修改rc.local 。按【i】键进入编辑模式，在最后添加代码：
```shell
sleep 60
cd /myApp/test
sh /myApp/test/startup.sh
 
#第一句为进入你项目所在的目录，我这里把项目放在/myApp/test下
#第二句执行该目录下的sh文件
 
##说明
#如果不提前进入所在目录，直接执行第二句，也会开机自启动，但是日志文件会在根目录下的log文件中。只有先进入，再执行，项目的日志文件才会在test文件夹下
 
##test文件中有jar包、startup.sh、以及jar包的日志文件logs
```
设置权限：
```shell
chmod +x /etc/rc.d/rc.local
chmod +x /myApp/test/startup.sh
```

## 环境
### python环境配置
```shell
# 1. 更新本地软件包索引（让 apt 知道有哪些最新版本的软件包可用）
apt update

# 2. 安装 Python 虚拟环境管理工具（python3-venv），-y 表示自动确认安装
apt install -y python3-venv

# 3. 创建项目目录（-p 确保父目录存在，若目录已存在也不会报错）
mkdir -p /opt/meeting-file-sync

# 4. 进入项目目录
cd /opt/meeting-file-sync

# 5. 在该目录下创建一个名为 venv 的 Python 虚拟环境
#    （这是独立于系统的 Python 环境，避免污染系统 Python）
python3 -m venv venv

# 6. 激活虚拟环境（激活后，终端前缀会显示 (venv)，且 python/pip 都指向虚拟环境）
source venv/bin/activate

# 7. 升级虚拟环境中的 pip 到最新版本（确保安装包时兼容性更好）
pip install --upgrade pip

# 8. 在虚拟环境中安装 pymysql 和 requests 包（不会影响系统全局）
pip install pymysql requests

# 9. 测试python环境
python -c "import pymysql, requests; print('OK')"

# 10. 测试需要下载的文件网络环境
curl -I "https://file.scjwwd.com.cn/zhjz24/20260811/2211731245568.JPG"
```

```shell
APP_HOME=$(cd $(dirname $0)/../;pwd)                    # shell脚本必须指定，因为脚本不会自动加载环境变量，不写的话导致出现此错误
app=$APP_HOME'/app.jar'    #jar包的决定路径
args='-server -Xms4096m -Xmx4096m -XX:PermSize=512m -XX:SurvivorRatio=2 -XX:+UseParallelGC'  #java程序启动参数，可不写
args1='--spring.config.location='$APP_HOME'/config/application.properties --logging.config='$APP_HOME'/config/logback-spring.xml --db.file='$APP_HOME'/config/config.db --logging.file.path='$APP_HOME'/logs/'
LOGS_FILE=/dev/null                           # 把打印的日志扔进垃圾桶

cmd=$1                                        #获取执行脚本的时候带的参数
pid=`ps -ef|grep java|grep $app|awk '{print $2}'`                # 抓取对应的java进程



startup(){
  aa=`nohup java -jar $args $app $args1 >> $LOGS_FILE 2>&1 &`
  echo "nohup java -jar $args $app $args1 >> $LOGS_FILE 2>&1 &"
}

if [ ! $cmd ]; then
  echo "Please specify args 'start|restart|stop'"
  exit
fi

if [ $cmd = 'start' ]; then
  if [ ! $pid ]; then
    startup
  else
    echo "$app is running! pid=$pid"
  fi
fi

if [ $cmd = 'restart' ]; then
  if [ $pid ]
    then
      echo "$pid will be killed after 3 seconds!"
      sleep 3
      kill -9 $pid
  fi
  startup
fi

if [ $cmd = 'stop' ]; then
  if [ $pid ]; then
    echo "$pid will be killed after 3 seconds!"
    sleep 3
    kill -9 $pid
  fi
  echo "$app is stopped"
fi
```
