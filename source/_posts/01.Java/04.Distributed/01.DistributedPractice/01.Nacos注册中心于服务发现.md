# 得赶上日程了

## nacos-注册/配置中心
### 基础入门
官网：[nacos 官网 | 快速开始](https://nacos.io/docs/v2.5/quickstart/quick-start)
下载：[nacos 官网 | 下载服务](https://nacos.io/download/nacos-server)
启动：在bin目录启动cmd，输入`startup.cmd -m standalone`启动nacos的服务端，访问：http://localhost:8848/nacos，就可以看到nacos的ui界面了，nacos server 账号密码都是nacos。

### 注册中心
将微服务注册到nacos中进行统一管理，首先微服务要引入nacos依赖：
```xml
<dependencies>
    <dependency>
        <groupId>com.alibaba.cloud</groupId>
        <artifactId>spring-cloud-starter-alibaba-nacos-discovery</artifactId>
    </dependency>
</dependencies>
```
然后服务在自己的properties或yml文件中配置：
```shell
# properties
server.port=8000
spring.application.name=service-order # 服务名字
spring.cloud.nacos.server-addr=127.0.0.1:8848 # nacos地址
```
启动服务，在nacos的服务列表里面就可以看到这个服务了。
### 服务发现
服务间的远程调用通过nacos发现对方的服务，然后进行调用，后续不用手动调，这里只要加上注解，两个API作为了解。
启动类加注解`@EnableDiscoveryClient`，然后在需要使用的地方注入，就能发现在nacos中注册的服务：
```java
@Autowired
NacosDiscoveryClient nacosDiscoveryClient;
public void nacosDiscoveryClientTest(){
    List<String> services = nacosDiscoveryClient.getServices();
    for (String service : services) {
        System.out.println("service = " + service);
        List<ServiceInstance> instances = nacosDiscoveryClient.getInstances(service);
        for (ServiceInstance instance : instances) {
            System.out.println("instance.getHost() = " + instance.getHost());
            System.out.println("instance.getPort() = " + instance.getPort());
        }
    }
}
```
远程调用服务中接口，可以在消费者的这一方配置：
```java
@Configuration
public class ConsumerConfig {
    @Bean
    public RestTemplate restTemplate() {
      //RestTemplate 是 Spring 框架提供的同步 HTTP 客户端模板类，它的核心作用是简化客户端与 RESTful 服务之间的 HTTP 通信。
        return new RestTemplate();
    }
}
```
之后，就可以开始调用生产者的接口了
```java
@Autowired
NacosDiscoveryClient nacosDiscoveryClient;
@Autowired
RestTemplate restTemplate;

//远程调用获取生产者信息
public Product getProductFromRemote(Long productId) {
    //1、获取到生产者服务所在的所有机器IP+port
    List<ServiceInstance> instances = nacosDiscoveryClient.getInstances("service-product");
    ServiceInstance instance = instances.get(0);
    //远程URL
    String url = "http://" + instance.getHost() + ":" + instance.getPort() + "/productId/" + productId;
    log.info("远程请求：{}", url);
    //2、给远程发送请求
    Product product = restTemplate.getForObject(url, Product.class);
    return product;
}
```

> 注册中心宕机了，还能调用吗？
> 可以调用，因为缓存中有地址。但如果对方服务宕机则也调不通。
> 原理
> 第一次远程调用要经过两个步骤：1.拿到nacos服务地址列表 2.给对方服务的某个地址发送请求。
> 第二次及后续：就会将步骤1省略，已经将地址列表放到缓存中了，即使nacos宕机也能远程调用，并且能负载均衡。

### 负载均衡
这个功能只能负载均衡注册到nacos的服务。首先，先引入依赖
```xml
<!--负载均衡-->
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-loadbalancer</artifactId>
</dependency>
```
然后进行测试：
```java
@SpringBootTest
public class OrderApplicationTest {
    @Autowired
    LoadBalancerClient loadBalancerClient;
 
    @Test
    public void test() {
      // 这里可以看到在启动多个生产者之后，回依次轮询调用
        for (int i = 0; i < 9; i++) {
          // 将nacosDiscoveryClient换为loadBalancerClient
            ServiceInstance choose = loadBalancerClient.choose("service-product");
            System.out.println("choose.getHost()+choose.getPort() = " + choose.getHost() + ":" + choose.getPort());
        }
    }
}
```
此外，负载均衡也可以用注解，在配置类RestTemplate()的`@Bean`这里加上`@LoadBalanced`，就可以更简单的调用：
```java
public Product getProductFromRemoteWithLoadBalanceAnnotation(Long productId) {
    //给远程发送请求；；service-product会被动态替换
    String url = "http://service-product/productId/" + productId;
    Product product = restTemplate.getForObject(url, Product.class);
    return product;
}
```
